装机是这样的。各个部件到货之后，只要把它们装在一起就可以了，可是部件的挑选要考虑的事情就很多了。

起因#

大约在半年前，我决定组装了一台新的台式电脑。时隔多年，又到了我与选择恐惧症斗争的环节。我的上一台台式电脑也是我自己挑选部件与组装的，并且服役了 5 年，陪伴我度过了整个大学的在校时光。

在离开校园并开始工作后，我想购买一台 4K 显示器（本文的 4K 是指 16:9 的 2160P，即 3840×2160）。尽管此前我用了很长一段时间的 1080P 显示器，但我对它的清晰度并不满意。当时作为学生的我，对于还处于高价的 4K 的显示器只能望而却步。刚好 @Frantic1048 有一个闲置的 4K 显示器，于是被我低价带我回了家，当时我并没有想到这是我掉入消费陷阱的开端……

在编写代码和阅读文档时，高分辨率显示器显著提高了文字的清晰度，甚至网页上的 UI 元素也因分辨率的提升变得更加细致，这非常令人满意。然而，我的 GTX 1060 显卡性能仅够支撑大型游戏在 1080P 分辨率下运行，能感觉到游戏的 UI 并不像平时使用的软件或网页那样清晰锐利。

如果游戏支持将 3D 渲染分辨率和 UI 分辨率分开设置，我可以将性能需求高的图形内容渲染在 1080P 下，而将性能需求低的 UI 运行在 4K 分辨率下，这样在不升级硬件的情况下也能拥有相对舒适的体验。然而，并非所有游戏都能如此设置。为此，我还研究了如何修改一些常见游戏引擎的配置文件以实现上述效果，但修改配置文件并不总能如愿以偿。

这里点名批评一下最近在玩的 《Granblue Fantasy: Relink》 的画面设置。

台式电脑还是笔记本电脑#

由于我仍然有一些便携需求，所以曾考虑过不组装台式电脑，而是购买一款游戏笔记本。最终，我还是选择了台式电脑。主要原因是我已经拥有一台能够满足开发需求的轻薄本，而且笔记本的散热性能远不如台式机，在需要大量计算的场景下，笔记本的噪音会比较大，这是我不太愿意接受的。

硬件挑选#

挑选思路#

由于我上一台电脑在用于开发用途时的性能表现并没有让我觉得不够满意，因此这次挑选硬件的主要目标是满足游戏需求。

考虑到我并不期望新电脑能以最高画质运行游戏，所以我没有选择高端型号（钱包不允许），中等性能/甜品级/性价比高的型号。为了减少日后维修带来的麻烦，会偏好品控评价较好的品牌和型号。

CPU: AMD Ryzen™ 5 5600#

AMD Ryzen™ 5 5600 在购买时，AMD Ryzen™ 5 5600 是性价比最高的几个型号之一。值得注意的是其 32MB 的三级缓存，相比之下，竞品 Intel® Core™ i5-12400F 只有 18MB。这使得 Ryzen 5 5600 在竞技类游戏（如《英雄联盟》、《Dota 2》、《CS: GO》等）的帧数表现明显优于竞品。

主板：技嘉 B550M-K#

尽管同样价格可以买到技嘉 B550M AROUS ELITE，但是技嘉 B550M-K 这一款主板可以在不借助 PCI-E 延长线的情况下，同时插入 3 槽宽度的显卡和 PCI-E 无线网卡。

然而，在购买并使用后我才发现这款主板没有 PBO（自动超频）功能，即使已经更新到了最新的 BIOS 版本。看到其他同型号用户的反馈也是如此。我比较认可的一个猜测是，这款主板的供电不如同芯片组的其他主板（从电感数量上可以看出，尽管这个方法并不绝对），这可能会影响超频的效果与稳定性，因此阉割了 PBO 功能。

另外，这款主板只有一个 F_USB 接口，而我之前使用的主板有两个。这意味着当我使用网卡上的蓝牙功能连接线插入这个接口后，机箱前面板的 USB 2.0 接口就没有 F_USB 接口可供连接至主板。最后，我选择将唯一的 F_USB 接口用于网卡连接，转而使用机箱后方的 USB 接口。幸运的是，前面板的 USB 3.0 接口连接线插的是另一个接口，所以仍然可以使用。

显卡：NVIDIA GeForce RTX™ 3060 Ti GDDR6X#

3060 Ti G6X 毫无疑问是当时性价比最高的 NVIDIA 显卡。尽管 4060 Ti 在售价提升的同时显著降低了功耗和发热，但其性能提升却犹如挤牙膏一般。

特别值得注意的是，与 3060 Ti 相比，4060 Ti 的显存大小没有提升，位宽却从 256 bit 降低到了 128 bit。尽管 NVIDIA 通过增加大量缓存来弥补位宽削减的劣势，但在高分辨率运行游戏这种依赖位宽的场景下，位宽削减带来的影响是相当显著的。我认为这是 NVIDIA 在销售策略上的手段（也被称为老黄精准的刀法），意在让那些希望以高分辨率运行游戏的玩家支付更高的价格购买更高端的型号。

考虑到我用来运行大型游戏的时间并不算多，我认为发热（需要风扇更高的转速散热，意味着更高的噪音）与功耗方面的劣势与它带来的优势相比，是可以接受的。

内存：光威 DDR4 64 GB#

由于 DDR4 内存已经进入生命周期末期，其价格变得相当低廉，64GB 内存的价格也变得可以接受。尽管我购买了 64 GB 内存，但实际上，我并不能真正利用这么大的容量，只是图个开心，现在已经有点后悔了……

另一方面，DDR5 内存由于刚刚进入市场，与高频率的 DDR4 相比，并没有显著的性能差异，但价格却贵了不少，这和当年从 DDR3 转向 DDR4 的时期类似。

对于光威内存的稳定性，我并没有太大的把握，尽管他们在内存条市场已经扎根许久。这一次的选择并没有遵循之前提到的挑选思路，仅仅是因为身边有人在使用这个品牌，并且它真的很便宜。

硬盘：铠侠 RC20 2TB#

铠侠的前身是东芝存储。

RC20 作为固态硬盘吧的「 吧盘」，尽管它的性能与它的竞品相比显得毫无竞争力，但是胜在较低的价格以及在巨大的出货量下仍然能保证极低的翻车率。

机箱：先马易大师 S1 雪装版#

这款白色机箱不仅外观漂亮，价格也很实惠，正好能容纳我的硬件配置。它不仅有玻璃面板的侧透设计，还拥有良好的风道，能够保证了内部的散热效果。

使用体验#

除了能以更高分辨率和更高画面设置运行游戏外，换了新电脑后，让我感觉到比较意外的是 Windows 11 变得更加流畅了（优化越来越烂了）……

这款显卡体积和重量都相当大，没有搭配支架使用半年后，我发现显卡的没有螺丝固定的一侧明显有一点弯了……
